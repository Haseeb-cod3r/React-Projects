## About The Project

![Product Screenshot](./public/Screenshot%202026-02-25%20144941.png)

CodeSense AI is an AI-powered code analysis platform built specifically for front-end developers. It helps you review, debug, and optimize your code instantly using intelligent AI insights.

With CodeSense AI, you can select your preferred language, framework, and feature, then simply paste your code. The AI analyzes your submission and provides:

✅ Smart Code Review

🐞 Debugging Assistance

⚡ Code Optimization Suggestions

Unlike generic code tools, CodeSense AI focuses entirely on front-end development, ensuring feedback is tailored for modern UI technologies and frameworks.

The platform not only generates improved code but also provides meaningful feedback to help developers understand mistakes, improve structure, and write cleaner, more maintainable code.

You can also customize your experience by selecting different themes, making the interface comfortable and developer-friendly.

## Getting Started

1️⃣ Clone the repository:

https://github.com/Haseeb-cod3r/React-Projects/tree/main/code-sense

2️⃣ Navigate to the project directory:

cd code-sense

3️⃣ Install dependencies:

 ```sh
npm install
   ```
🔑 Environment Variables

Since your project uses Groq SDK, create a .env file in the root directory:

 ```sh
VITE_GROQ_API_KEY=your_api_key_here
```

🚀 Run the Development Server

Start the app locally:

 ```sh
npm run dev
```
Your app will be running at:

 ```sh
http://localhost:5173
```

🏗️ Build for Production

To create a production build:

 ```sh
npm run build
```

## Usage

Using CodeSense AI is simple and straightforward. First, paste your front-end code into the editor, then select your preferred language, framework, and the feature you want to use Review, Debug, or Optimize. After configuring your options, click the Analyze button and the AI will process your code and generate improved code along with detailed feedback. You can use the Clear button to instantly remove code from the editor, the Copy Code button to copy the AI-generated output with one click, and switch between different themes to customize your coding experience.
